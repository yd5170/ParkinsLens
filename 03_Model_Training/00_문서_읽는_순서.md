## 2. 코드 (역할별, 2026-07-24 폴더 재구성 반영)

논문 파이프라인 5단계(Model-1/2 학습, Model-3 CCA, Model-4 WOA, GB 평가)에 맞춰
폴더를 정리함 - "모델 학습"(신경망 가중치를 실제로 갱신하는 것)과 "특징 엔지니어링"
(이미 학습된 모델의 중간출력을 수학적으로 가공하는 것, 학습 아님)을 명확히 분리:

### 2-1. `02_Model_Definition` — 모델 구조 정의
- `ablation_models.py` — `CNN3D_Base/Variant1/Variant2/Variant3`(Table3 ablation)
- `models.py` — 최종모델 `CNN3D`(Figure2 직접 재현, ablation과 별개 해석), `ResNet3D`

### 2-2. `03_Model_Training` — Model-1(3D-CNN)/Model-2(3D-ResNet) 학습만
- `train_ablation.py` — Base/V1/V2/V3 학습. `--kfold 5|10|15`로 Table5의 k-fold CV
  재현 가능(`run_kfold()`). 학습 루프는 `train_loop()`로 공용화(epoch별
  precision/recall/f1 기록).
- `train_cnn3d.py` — 최종모델 CNN3D(Figure2) 학습
- `train_resnet.py` — ResNet 학습(`run_kfold_resnet()`도 지원, `train_loop()` 재사용)
- `dataset.py` — `get_holdout_split`(70/15/15), `get_kfold_splits`(Model-3/4 평가용
  train/test만), `get_kfold_splits_with_val`(CNN/ResNet 학습 자체의 k-fold용
  train/val/test 3분할)
- `results/`, `checkpoints/`, `reports/` — 학습 결과 JSON/가중치/Excel 보고서
- `archive/` — 로그 파일, 스테일 결과, 프로파일링 스크립트, 폐기된 이전 버전 CCA/WOA
  스크립트 등 학습과 무관한 것들(정리 이력 보관용, 재사용 안 함)

### 2-3. `04_Feature_Engineering` — Model-3(CCA) + Model-4(WOA), 학습 아님
**2026-07-24 논문 원문 재검증 후 정정 완료 - 이제 이 폴더가 유일한 CCA/WOA 기준
구현.** (이전엔 03_Model_Training에도 별도로 CCA/WOA를 새로 만들어서 이 폴더와
두 갈래로 갈라져 있었으나, 원문 대조 결과 이 폴더 쪽에 있던 실수를 정정하고 하나로
합침 - 아래 "정정 내역" 참조)
- `extract_features.py` — Variant3/ResNet 체크포인트에서 FC-1/FC-2/FC-4 추출,
  Algorithm1(원소별 선택)로 FV-3(1000차원, 논문 p.6 "FV1×1000, FV2×1000") 생성
- `cca_feature_fusion.py` — `cca_fuse()`: CCA n_components=수학적 최댓값(임의 상한
  없음), Eq6(concat)/Eq7(합산) 둘 다 반환(논문 "concatenated or summed up")
- `woa_feature_selection.py` — `binary_woa_feature_selection()`: Table7 그대로
  (population=100, iterations=200, bounds=[0,1], 독립실행 20회), fitness는 3-fold
  교차검증(`cross_val_score`) 채택, 이진화는 위치값을 threshold와 직접 비교
  (Table7 "bounds=0 and 1" 근거 - sigmoid 변환은 시도했다가 결함 발견 후 되돌림)
- `run_real_pipeline.py` — 위 세 개를 실제 체크포인트 데이터로 이어붙여 전체
  Model-3/Model-4 파이프라인을 한 번에 실행하는 통합 스크립트(신규)

**정정 내역(2026-07-24, 논문 원문 대조 결과)**:

| 항목 | 정정 전(구버전) | 정정 후(현재) | 근거 |
|---|---|---|---|
| FV-3 차원 | 2000(단순 concat, Algorithm1 미구현) | **1000**(Algorithm1 원소별 선택) | 논문 p.6 "FV1×1000, FV2×1000", p.7 "2000 features from **both**" |
| CCA n_components | 임의 상한 100 | **수학적 최댓값**(min(n-1,p,q)) | 논문에 상한 근거 없음 |
| CCA 융합 방식 | concat(Eq6)만 | **Eq6+Eq7 둘 다** | 논문 "concatenated **or summed**" |
| WOA fitness | (해당 없음, 새로 추가) | 3-fold CV | 논문의 전반적 교차검증 관행과 일관 + 실측상 baseline 대비 개선 확인 |
| WOA 이진화 | (해당 없음, 새로 추가) | 직접 threshold 비교 | Table7 "bounds=0 and 1" |

### 2-4. `05_Model_Evaluation` — GB 분류기 학습·평가
- `train_gb.py` — CCA 융합 결과(Eq6 vs Eq7) GB 학습·평가(04에서 저장한
  `fused_*.npz` 사용)
- `kfold_model3.py` — Model-3(CCA+GB) k-fold(5/10/15) 평가, Table6 재현
- `compute_confusion.py` — 체크포인트 재추론으로 confusion matrix/weighted 지표 계산
  (ablation 5개 + resnet3d + cnn3d 전부 지원)
- `ml_classifiers_kfold_eval.py` — 2026-07-03 세션 작성, weighted 평균 사용

**미해결 - 사용자 확인 필요**: macro vs weighted 평균 중 무엇을 기준으로 삼을지
(클래스 불균형 Control 110/Prodromal 58/PD 135 상황에서 둘의 값이 꽤 다를 수 있음).
`ml_classifiers_kfold_eval.py`는 weighted를 쓰는데 나머지 대부분은 macro를 씀 -
통일 필요.
